# 演示录屏（约 3 分钟）

沙箱。先 `npm run demo`（没有 `.env` 时用 `.env.example` 的本地降级）。打开 http://127.0.0.1:3000。不要执行 `submit-payment`，不要填写 session，不要使用生产密钥。两段交易号都留空。这不是一笔已完成的支付。

## 成功一单

填入环境文件里的两个令牌。沙箱时间设为 2026-10-09 10:00 +08，保存授权，用户确认，签发令牌。

输入 `会议室缺笔和 A4 纸，下周开会用`，点「听懂并出方案」。口播：黑色签字笔 1 件、800 分；A4纸 1 件、2500 分；总价 3300 分；并念剩余预算。这时还没有收银台。

点「确认方案并生成收银台」。画面出现 page.pay 链接和官方命令。停在这里，不执行命令。

交易号：（留空）

## 超额后手动改单

再签发一枚令牌。输入 `100支笔`，点「听懂并出方案」。口播：仍是黑色签字笔 100 件、单价 800 分，超出单笔上限。系统没有改成 1 分笔，也没有自动把数量改小。

演示员自己把输入改成 `1支签字笔（1分试买）`，再点「听懂并出方案」，再点「确认方案并生成收银台」。这是人手改口，不是产品在超额后自动换款。不要执行支付命令。
