# 演示录屏

沙箱页面。不要运行 `alipay-bot submit-payment`，不要填写交易号或 session id，不要使用生产密钥。下面两段都把交易号留空。

## 自然语言成功一单

1. 以 `LOCAL_DEGRADED=1` 启动，打开页面。
2. 填入本机的管理令牌和用户令牌。把沙箱时间设为 `2026-10-09 10:00 +08`，保存默认授权，再点「用户确认授权」。
3. 点「签发支付令牌」。
4. 在自然语言需求里输入：`会议室缺笔和 A4 纸，下周开会用`。点「听懂并出方案」。
5. 画面上应看到黑色签字笔 1 件、单价 800 分，A4纸 1 件、单价 2500 分，总价 3300 分，以及单笔上限、今日剩余、总额剩余。此时还没有收银台链接。
6. 点「确认方案并生成收银台」。第 3 步出现原始 page.pay 链接和 `submit-payment` 命令。不要执行这条命令。
7. 交易号：`（留空）`。

## 超额拒付

1. 重新签发一枚令牌。输入 `100支笔`，点「听懂并出方案」。
2. 方案仍是黑色签字笔 100 件、单价 800 分，总价 80000 分，并说明超出预算。不会改成 1 分试买，也不会把数量改小后再提交。没有收银台链接。
3. 也可以点第 5 步的「超额」。返回 `over_budget`。拒付不消耗令牌，同样不会自动换便宜款。
4. 交易号：`（留空）`。
